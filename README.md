# Sapphire 简体中文云端编译

从固定的社区简体中文源码提交构建，并应用本仓库内经过审核的公共构建补丁。

此临时签名安装包不会注册 Sapphire 的特权辅助程序，也会跳过辅助程序和电池控制的引导页。电池充电控制及其他依赖辅助程序的系统集成功能在此版本中不可用；设置页会显示说明。这样可以避免旧辅助程序仍要求原开发者签名时不断出现 SAP-H1 弹窗。此改动不影响原版 Sapphire 或正式签名的版本。

此社区版本也关闭验证码识别、自动复制和专用灵动岛弹窗，并隐藏相应设置。普通通知功能仍可使用；如果仍启用通知权限，Sapphire 仍可能读取包含验证码的普通通知内容。手动复制的内容仍可能进入系统剪贴板或应用的剪贴板历史，若不需要请另外关闭剪贴板监控。
